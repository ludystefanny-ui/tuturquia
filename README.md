# Tu.turquía · A la mano

Tablón comunitario para latinas en Turquía: trabajos, alquileres, ventas, servicios y recomendadas de confianza.

- `index.html`: el sitio completo (una sola página).
- `privacidad.html`: política de privacidad.
- `supabase/`: SQL de la base de datos (tablas y reglas de privacidad).

Se publica solo en Cloudflare Pages cada vez que cambia la rama `main`.
No hay paso de compilación: Cloudflare sirve los archivos tal cual.
